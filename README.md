# Infra.Coop
Es un proyecto de Data Cooperativas Latinas como parte del Fellowship Mozilla 2024-2026 

Objetivo: 

Visualizar el estado actual de los datos (abiertos, estadísticos, ciudadanos existentes) VS el marco normativo vigente para identificar  Brechas de Datos. 

Crear un algoritmo alimentado por las preguntas de las usuarias/participantes que permita evidenciar el aporte de los datos que queremos en el criterio de calidad.  A través del Algoritmo cooperativo evaluar el aporte hacia un nuevo criterio de calidad.

Evidenciar que la manifestación “los datos que queremos” implica un giro político en los criterios de calidad de los datos, el proceso del ciclo del dato y su gobernanza contrariamente al estado actual.

Dimensiones de la infra

Back-end: Base de datos de normativas y datos. Agendas: tecnología, género. Normativas basales: Agenda Futura de cooperación digital, OGP, Beijing.

Front-end: Dashboard con campo inicial de pregunta sobre datos, resultados (basados en la contrastación de la base de datos), evolución de la brecha o aporte de evidencia del cambio a partir de las narrativas/necesidades preguntadas por las usuarias para los datos que queremos.

Algoritmo: modelo cooperativo de maduración del criterio de calidad del dato a través de atributos diversos derivados de principios de datos abiertos, construídos por la ciudadanía e inclusivos.
